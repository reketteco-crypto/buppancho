# 更新と切り戻し

1. `scripts/deploy/update.ps1`を使い、更新前バックアップ、イメージ作成、マイグレーション、アプリ更新の順で実行する。
2. バックアップ失敗時は更新を中止する。
3. アプリ更新だけが失敗した場合は以前のイメージタグへ戻す。DBマイグレーション後にデータを戻す必要がある場合は、別環境で復元検証してから停止時間を確保する。
4. PostgreSQLのメジャー更新は通常更新へ含めず、dump/restoreによる別作業とする。

Cloudflare Tunnelはフェーズ0では有効化しません。将来は`cloudflared` profileへトークンを渡し、Cloudflare Accessの内側でのみ公開します。ルーターの受信ポートは開放しません。
