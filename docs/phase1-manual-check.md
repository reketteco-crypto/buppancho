# フェーズ1 手動確認

## 事前準備

- 入力者、販売部門、対象年度を選択する。
- 「その他・設定」で保管場所と仕入先を1件以上登録する。
- 商品は独立画面からも仕入れ登録内からも作成できる。

## 統合仕入れ登録

1. 「新品・同一商品」で数量50、原価50,000円の明細を追加する。
2. 「中古・一点物」で個別状態・採寸・原価を持つ明細を追加し、同じ仕入れ内に混在できることを確認する。
3. 仕入総額と全明細合計が不一致なら保存できず、一致すれば下書き保存・確定できることを確認する。
4. 詳細設定から新品の個体管理、中古の数量管理も選択できることを確認する。
5. 空欄の個体コードが確定時に`UNIT-000001`形式で採番され、再送でも在庫が重複しないことを確認する。

## 仕入画面内の商品・バリアント作成

1. 「新しい商品を作成」を開き、商品名、既定区分、既定追跡方式を入力する。
2. 色「黒, 白」とサイズ「M, L」から4組を生成する。
3. 不要な組合せを除外し、バリアントコードを編集して明細へ選択する。
4. 保存失敗時に商品・バリアント・仕入下書きが残らないことを確認する。
5. 商品詳細で商品合計とバリアント・追跡方式別の在庫数量、原価、平均／個別原価を確認する。

## 検索・在庫移動・取消

- 商品名、商品コード、バリアントコード、属性値、個体コードで検索する。
- 同じバリアントの数量管理在庫と個体管理在庫が別の原価残高になることを確認する。
- 場所移動、廃棄、紛失、私用、増減調整と履歴を確認する。
- 未移動の確定仕入れは理由付きで取消でき、後続移動がある場合は拒否されることを確認する。
- ロック済み年度では確定・取消・在庫調整が拒否されることを確認する。
